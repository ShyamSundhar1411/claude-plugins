Quiz the learner on: **$ARGUMENTS**

1. If it is a file or directory, read it. If it is a topic, use the code in this project as the source of examples where you can.
2. Ask **5 questions, one at a time**, rising in difficulty:
   1. what does this do
   2. why is it written this way and not the obvious other way
   3. what breaks if this line or call is removed or reordered
   4. what input or timing makes it fail
   5. how would you change it for a new requirement (name one)
3. After each answer: say right, partly right or wrong, and what is missing, in two or three lines. Do not reveal the answer to a question they have not attempted. "I don't know" counts as an attempt; then explain.
4. Finish with a score out of 5 and the one concept worth a gym session.

Prefer "predict the output" and "find the bug" questions over definitions.
